ROOT CAUSE

Nearly everything still open below traces back to one fact: no live Fastmail JMAP session and no live Anthropic API session exist in any environment this project has been built in. JmapClient's five methods and JmapPushTrigger.wait() are settled-shape, tested NotImplementedError stubs — real signatures, real passing tests asserting the correct raise, not missing work. Everything downstream of that connection (rule dry-runs against recent mail, live verdicts, a systemd unit staying up, confidence tuning, rate-limit handling) stops at that same wall.
